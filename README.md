# Odin Recipes - Pizza Page

A simple recipe webpage built while working through The Odin Project's HTML foundations course. 
The site displays a homepage (`index.html`) linking to a detailed pizza recipe page (`pizza.html`), 
including ingredients and step-by-step cooking instructions.

## What it does
- Homepage with navigation to the recipe
- Pizza recipe page with an ingredients list and numbered cooking steps
- Built to practice semantic HTML structure (headings, lists, links)

## Tech used
- HTML5

## Live demo
https://moahmad809.github.io/odin-recipes/

## What I practiced
- Structuring content with headings, unordered and ordered lists
- Linking between pages using relative links
- Organizing a multi-page HTML project
